# Burhan Nexus License Key Generator (admin only)

Windows desktop tool for the software owner to issue and manage **Lifetime Pro** license keys for
Burhan Screen Capture Pro. Do **not** distribute it to customers.

* Generate New License — customer name, optional email, product, license type (Lifetime Pro), Device ID lock,
  device limit, notes → signed `BNX-SC-PRO-…` key, License ID, creation date, activation status
* Copy License Key / Copy customer message / Export License (`.bnxlic`)
* License History — search, details, record activation, revoke / reinstate, export CSV
* Revocations — export a signed revocation list for the app
* Signing Key & Backup — public key for the app, backups, restore, change password, lock

See `docs/LICENSING.md` for the format and the full selling workflow.
